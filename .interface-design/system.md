# ProjectHub — Paper

게임 스튜디오 디렉터가 아침에 열어 "밤새 에이전트가 뭘 했나 / 내가 승인할 게 뭔가"를 훑는 도구.
느낌은 **작업 책상 위의 종이** — 조용하고 따뜻하고, 색은 상태에만.

구현 위치 (Mother `~/projecthub-web`)
- `src/app/theme-paper.css` — 색·면·타입 (테마 층)
- `src/app/paper-components.css` — 구조·인터랙션 (컴포넌트 층)
- `src/components/paper/{Thread,Bits}.tsx`
- 켜기: `.env.production` 의 `NEXT_PUBLIC_APP_THEME=paper` → 빌드 → 재기동

## 방향

시그니처는 **스레드**다 — 사람과 에이전트가 같은 방에 있고, 그걸 색이 아니라 **형태**로 구분한다.
사람은 잉크 도장 아바타 + 흰 종이, 에이전트는 테두리만 있는 아바타 + 파인 면 + 왼쪽 잉크 스트립,
시스템은 아바타 없는 한 줄 괘선. 연속 발언은 5분 안이면 묶어서 머리글을 생략한다.

## 토큰

| | 값 | 비고 |
|---|---|---|
| 책상 / 종이 / 파인면 | `#fbf9f5` / `#ffffff` / `#f4f1ea` | 색상은 하나, 명도만 이동 |
| 잉크 4단 | `#1a1815` `#3d3833` `#6b645c` `#8a8279` | 15.0 / 9.6 / 5.4 / 3.6 : 1 |
| 괘선 3단 | `rgba(26,24,21,.10 / .17 / .28)` | |
| 액센트 | `#e1791b` (면·선·점) / `#8a4308` (글자) | **오렌지는 흰 배경 2.7:1 — 글자로 쓰지 않는다** |
| 상태 | ok `#2e7d57` · warn `#a96a10` · err `#c0392f` | 색이 의미를 갖는 유일한 자리 |

분홍·보라 같은 장식 색은 전부 액센트로 흡수한다. 60/30/10.

## 타입

- 디스플레이 **Fraunces** / 본문 **DM Sans** + Pretendard(한글) / 수치 **Geist Mono** 탭룰러
- 전부 `next/font/google` = 자체 호스팅. **폰트 변수는 `<html>` 에 붙인다**(body 에 두면 테마 토큰이 못 읽음)
- 기준 15px · 배수 1.25 → 12 / 13.5 / 15 / 19 / 23 / 28
- 위계는 크기 하나가 아니라 **서체·웨이트·색 3축**. 큰 글자는 트래킹 −0.014em
- 한글 제목은 세리프 대신 Pretendard 700 (작은 크기의 한글 명조는 가독성이 떨어진다)

## 깊이 · 간격

- **보더 전용.** 그림자는 진짜 뜨는 것(shadow-lg 이상)만 1px 링 + 얕은 2단
- 라디우스 입력 4 · 카드 6 · 모달 10 · 원형은 아바타/점/토글만. **동심원**: 부모 7 − 패딩 2 = 자식 5
- 종이 그레인 SVG turbulence `opacity .028` — 이게 없으면 그냥 흰 테마다
- 읽는 줄은 `max-width: 62ch`

## 모션

`--pp-ease: cubic-bezier(.23,1,.32,1)` · 프레스 `scale(.985)` 120ms · 전환 140~160ms ·
`prefers-reduced-motion` 에서 전부 정지. `transform`/`opacity` 만 애니메이트.

## 함정 (실측)

1. **유틸리티 재매핑만으론 크롬이 안 바뀐다.** 상단바·독이 인라인 `style` 로 globals 토큰
   (`var(--neon)`/`var(--line)`)을 참조한다 → paper 스코프에서 **토큰 자체를 재정의**해야 한다.
2. 남은 하드코딩(`rgba(6,11,22,..)` 헤더, `rgba(34,211,238,..)` 활성 탭)은 `header.fixed` /
   `[style*="rgba(34,211,238"]` 로 개별 제압.
3. 검수는 Mother 의 playwright(`~/.hermes/hermes-agent/node_modules/playwright`)로 실제 렌더를 찍는다.
   내부키 헤더로 미들웨어 통과. **서버엔 한글 폰트가 0개**라 스크린샷의 두부는 헤드리스 한정.

## 구성 규칙 (2026-08-11 적용)

- **지표 줄은 주인공 하나 + 띠 하나.** `.pp-statbar` = `minmax(230px,1fr) 2.15fr`.
  주인공은 44px 모노, 띠는 21px. **주인공은 상황에 따라 바뀐다** — 오류가 있으면 오류가,
  없으면 진행 중이 올라온다. 같은 크기 카드 N개는 초점이 없다는 뜻이다.
- **셸 폭 1400px** (`main > div`). 1680 은 칸반 4열(약 1000px)에도 남고 문장이 늘어진다.
  진짜 넓어야 하면 자식에 `.pp-wide`.
- **흐름은 원이 아니라 선.** `.pp-rail` — 회전 오비탈(정적 라벨 6개짜리 장식, 420px)을 대체.
  단계별 상태를 모르면 **칠하지 않는다**; 실행 수는 머리글에만 적는다.

## 지켜야 할 두 가지 (여기서 어긴 적 있음)

1. **모르는 것을 아는 척 칠하지 말 것.** 레일의 "실행 중" 단계를 `i===2` 로 칠할 뻔했다 —
   node-runs 는 총계만 준다. 근거 없는 상태 표시는 나머지 표시의 신뢰도까지 깎는다.
2. **상태 자리에 상수를 박지 말 것.** 음성 패널이 조건 없이 `LIVE` 를 띄우고 있었고,
   같은 화면 상단은 `OFFLINE` 이었다. 실제 heartbeat 로 교체.

색 예산도 같은 규칙이다 — 팀 legend 4개가 각자 다른 하드코딩 색(`#22d3ee`/`#a78bfa`/`#f472b6`)을
쓰고 있어서 legend 하나가 화면의 색을 다 썼다. 팀 구분은 라벨이 이미 한다 → 전부 `var(--text-dim)`.
