## 아직 완료되지 않은 항목

### 1. 실제 팀 주소 HTTPS·터미널 WSS — 기술 작업 미완료

Ubuntu Tailscale은 `NeedsLogin`, 최근 등록 요청 오류는 `unexpected EOF`입니다. 제어 서버의 HTTPS JSON 응답과 실제 Noise handshake/whoami는 성공하므로 모든 인터넷 통신이 막힌 상태는 아닙니다. 그렇다고 기기 등록이 성공한 것도 아닙니다. 등록 오류의 정확한 원인은 확정하지 않았습니다.

더 중요한 추가 실측은 **새 서버의 `tailscale serve status --json`이 `{}`**, 즉 팀 주소를 서비스로 연결하는 Serve 설정이 없다는 점입니다. 호스트 리스너에도 443은 없고 웹/게이트웨이는 loopback 3000/3001입니다. 계정 승인 후에도 HTTPS 및 `/gateway/term` WSS 전달 설정과 원격 브라우저 검수가 필요합니다.

이 PC에서 팀 주소 `newplay.tailf6f809.ts.net`은 기존 주소 100.111.77.39로 해석되고 HTTPS가 시간 초과됐습니다. 새 등록 기기의 주소 100.72.201.90과 다릅니다. 팀 기기 목록에서 새 기기는 Offline입니다.

근거: `server-readonly-check.log`, `server-connectivity-detail.log`, `server-final-details.log`, `current-observations.json`. RA-01의 실제 공개 경로/DB 일치 및 RA-02의 원격 WSS 접속 종료 조건은 아직 충족하지 않습니다.

### 2. 실제 HP 정상 종료·재부팅·USB 안정성 — 미확인

연속 3일 가동과 현재 USB 인식은 확인했지만, 그 사이 물리 재부팅은 없었습니다. 현재 부팅 초기에 NVMe APST 및 ACPI BIOS 오류가 기록됐고, 현재 부팅의 조회된 커널 심각 오류 로그에는 이후 새 패닉이 없었습니다. 새 crash 파일도 보이지 않았습니다. 이전 패닉의 원인·재현·해결을 증명한 것은 아닙니다.

새 Ubuntu VM의 재부팅 성공은 HP의 BIOS/그래픽/USB 부팅 검수를 대체하지 않습니다. 이번 검수 중 HP를 강제 종료하거나 재부팅하지 않았습니다.

### 3. 실제 계정 작업·프로필 효과·외부 기능 — 담당자 검수 필요

- 개인 Claude 토큰 파일 0개, 개인 프로필 0개, 작업 세션 0개입니다. 실제 개인 계정 작업 한 건과 충분한 활동에 따른 프로필 효과는 검증되지 않았습니다.
- 실제 Google OAuth 로그인과 인수자 본인의 Ubuntu/NewPlay/서비스 관리자 권한은 기존의 합성 로그인 시험으로 대체할 수 없습니다. 다른 분의 계정 로그인을 전달자에게 맡기지 않습니다.
- LiteLLM URL은 미설정입니다. 사용 대상으로 정할 LiteLLM·음성·디자인 등 외부 기능은 별도 설정과 실계정 검수가 필요합니다. 사용하지 않기로 정한 기능까지 임의로 설치하지 않았습니다.
