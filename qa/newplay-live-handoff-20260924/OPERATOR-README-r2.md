2. 운영자 전용 폴더에 풉니다. Ubuntu에서 `sha256sum -c SHA256SUMS`로 내부 파일을 검사합니다.
3. `03-guides/ACCEPTANCE.md`에서 담당자와 권한을 확인합니다. 파일을 받았다고 계정 관리 권한까지 이전되는 것은 아닙니다.

5. 실제 팀 Git, Tailscale/HTTPS/WSS, 인수자 본인 계정 업무와 HP 물리 재부팅을 확인하고 인수를 마무리합니다.
