# NewPlay 운영자 종합 전달본 — 2026-09-24

**지정된 운영 인수자에게 전달할 파일입니다. 실제 운영 비밀 설정과 데이터가 든 비암호화 백업을 포함합니다. 일반 팀원에게 공유하는 ZIP이 아닙니다.**

이 ZIP 하나에 기존의 검증 백업, 최신 전체 개발 소스, 최신 검증 기록, 역할별 안내를 모았습니다. 이전 패키지를 찾아 조합할 필요가 없습니다. 다만 **백업 데이터는 9월 18일 기준이고, 소스는 9월 23일 반영본 기준**입니다. 오늘 서버를 새로 백업한 통합 이미지라고 설명하면 안 됩니다.

## 받으면 무엇부터 하나요?

1. 외부 `.zip.sha256`과 ZIP의 SHA-256을 비교합니다. Windows는 `Get-FileHash -Algorithm SHA256 파일명.zip`으로 확인할 수 있습니다.
2. 운영자 전용 폴더에 풉니다. Ubuntu에서 압축을 푼 폴더의 `sha256sum -c SHA256SUMS`를 실행합니다.
3. `03-guides/ACCEPTANCE.md`에서 담당자·최종 팀 주소를 정합니다. Git/OAuth/Tailscale/Ubuntu/NewPlay 관리자 권한은 기존 관리자와 인수자가 직접 확인합니다.
4. 개발 담당자에게는 `01-current-source`의 개발자 ZIP과 해시만 전달할 수 있습니다. 일반 팀원은 사용 안내와 확정된 접속 주소를 받습니다.
5. 현재 운영 PC는 이미 9/23 수정이 반영된 상태라는 마지막 기록이 있습니다. **오래된 백업을 그 PC 위에 복원하거나 누적 패치를 다시 적용하지 않습니다.**
6. 새 PC 복구가 필요하면 `03-guides/RECOVERY.md`와 기존 백업 안의 운영자 복구 안내를 읽습니다. 9/18 데이터로 돌아가는 것을 먼저 확인하고, 최신 데이터가 필요하면 현재 서버의 수정 이후 백업을 확보합니다.
