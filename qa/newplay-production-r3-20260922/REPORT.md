## 남은 실제 장애: 팀 Git 원격 접속

기존 webstore 저장소의 원격은 `github-webstore:blocore/webstore.git` 형태입니다. Ubuntu와 작업대 모두 `ssh -G` 결과가 `hostname github-webstore`여서 GitHub 주소로 바뀌지 않으며, 실제 원격 조회는 **이름 해석 오류**로 실패합니다. HTTPS 주소 시험도 비공개 저장소 접근 인증이 필요해 실패했습니다.

따라서 현재 서버에 있는 코드의 탐색·편집·자동 변경 감지는 동작하지만, 팀 저장소의 **‘Git 최신 코드’는 502 안내가 나오고 원격 최신 커밋을 가져오지 못합니다.** 기능 전체가 운영에서 완주했다고 판정하지 않습니다.

다음 작업은 운영 담당자가 확인한 실제 Git URL, 해당 저장소 접근 권한, 개인 작업대용 Git 인증 방식에 맞춰 SSH 별칭/접속을 구성하는 것입니다. Claude 구독 로그인과 Git 인증은 별개입니다. 다른 사람의 토큰이나 기존 배포 비밀키를 개인 작업대에 복사하지 않았습니다. 전역 원격 URL도 임의로 바꾸지 않았습니다.
