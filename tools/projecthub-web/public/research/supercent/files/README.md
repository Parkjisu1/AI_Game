## 수집 범위 — 전수 확보 완료가 아님

- 조사일: 2026-09-21. 대상은 `medium.com/supercent-blog` 발행 글이다.
- 고유 글 URL **123개**를 식별했다. RSS 본문 **106개**, 웹 본문 **9개**를 확보·확인했고, **8개**는 검색 발췌/페이지 셸 수준이다. 통합 목록에서 상태를 구분한다.
- 이 중 PM 분석의 핵심 출처 **28개**를 근거 카드로 정리했다. 전체 123개에 동일한 깊이의 PM 분석을 했다는 뜻은 아니다.
- RSS 주소 **105개**를 발견·시도했다. 일반 아카이브는 HTTP 403, 후속 RSS는 HTTP 429/Cloudflare challenge가 발생했다. 지연 재시도 후에도 반복되어 체크포인트를 남겼다.
- 정상 반환된 피드 중 **9개**는 10개 항목 상한에 닿았다. RSS·검색 결과만으로 블로그의 전체 글 수를 증명할 수 없으므로 **전수 크롤링 완료로 표시하지 않는다.**
- 월별 주소 45개도 확인했으나 많은 주소가 실패하거나 연도별 페이지로 이동했다. 연도 페이지의 일부 목록을 해당 월 전체 목록으로 오인하지 않았다.
- 본문 속 모든 영상·이미지의 내용을 전수 추출한 것은 아니다. 광고 실험의 핵심 그래프 3개는 직접 확인했다.
- 날짜는 원래 RSS UTC 시각 또는 웹 표시일을 유지했다. 일부 글에서 하루 차이가 있어 단일 시간대의 발행일처럼 합치지 않았다.
- 결과물은 원문 재전재 대신 출처·메타데이터·압축 요약·실행 가설로 구성했다. 분석용 RSS 본문 임시 캐시는 OS 임시 폴더에 있으며, 문서·CSV는 그 캐시 없이 읽을 수 있다.

## PM 해석에서 지킨 구분

1. 공개 성과와 우리 게임 예상 성과를 구분했다. Sort에서 직접 입증되지 않은 변경은 가설이다.
2. D1의 %와 %p, 설치 전환과 리텐션, 광고 조회와 수익을 구분했다.
3. 여러 변경을 합친 전후 결과를 특정 기능의 단독 인과 효과로 쓰지 않았다.
4. 현재 빌드·기저 D1·국가·OS·테스트 한도가 없어 실제 게임의 결함·CPI 합격선을 지어내지 않았다.
5. 조직 문화·채용 글은 목록에 보존하되 직접적인 리텐션 근거로 쓰지 않았다.

## 재현 명령

저장소 루트 `E:\AI`에서 실행한다. 재수집은 서버 접근 상태에 따라 실패할 수 있다.

```powershell
node output/supercent-research-2026-09-21/collect.mjs
node output/supercent-research-2026-09-21/build-report.mjs
node output/supercent-research-2026-09-21/decision-math.mjs
```

`collect.mjs`는 피드의 공개 태그를 따라가며 글 ID로 중복을 제거하고, 요청 실패를 기록한다. 429가 세 번 연속이면 정지한다. 피드 큐가 비어도 RSS 상한 때문에 전체 발행물 완전성을 보장하지 않는다. `articles.json`은 RSS 자료, `web-supplement.json`과 `additional-discovery.json`은 웹 확인 보완 자료다. 최종 목록은 `catalog.json`이다.

웹 확인은 조사 도중 브라우징 도구로 수행했으므로 RSS 스크립트 하나만으로 그 과정을 재현할 수는 없다. 나중에 새로운 RSS 글을 확보하면 기존 근거 카드까지 자동 검토되는 것은 아니다. 통합 목록을 갱신한 뒤 별도 검토해야 한다.

DB 검색은 `node scripts/db-search.js --collection code_expert --genre generic --tag crawler`와 `code_base` 동일 조건으로 수행했다. 반환 후보는 점수 0.14~0.15의 게임 유틸리티로 이 조사 도구에 부적합했다. 검색 결과가 0개였다고 기록하지 않았다. 실제 게임 코드·설정·배포·광고 집행은 변경하지 않았다.

남은 작업은 접근 제한이 해소된 뒤의 미수집 범위 보완과 실제 게임의 기저 지표·빌드로 첫 실험을 확정하는 것이다. 현재 산출물만으로 D1 45% 달성이나 수익성을 검증한 것은 아니다.
