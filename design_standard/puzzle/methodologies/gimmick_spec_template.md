# 기믹 명세서 템플릿 — 퍼즐 장르 공용

> 퍼즐 게임의 기믹(blocker, modifier, special object)을 명세하는 표준 양식.
> 각 기믹마다 동일한 구조로 작성하여 디자인 의도/난이도 레버/피드백을 명확히 분리.
> 출처: BalloonFlow_기믹명세 (12종 기믹 사례) → 장르 일반화

---

## 0. 명세서 구조

각 기믹은 **5개 섹션**으로 작성:
1. 기본 정보
2. 동작 규칙
3. 난이도 레버
4. 디자인 의도
5. 피드백

---

## 1. 공통 용어 섹션 (문서 상단 1회)

기믹 명세 전체에서 사용할 용어를 먼저 정의:
```
- 필드 (Field): <제거 대상이 배치되는 메인 영역 정의>
- 큐 (Queue): <입력 자원이 대기하는 영역 정의>
- 입력 단위: <유저가 즉시 다루는 자원 단위>
- 매칭 규칙: <같은 색? 같은 모양? 인접 3개?>
- 실패 조건: <언제 실패인가>
- 클리어 조건: <언제 클리어인가>
- 기믹 카테고리: 필드 / 큐 / 양쪽 (기믹이 어디에 작용하는가)
```

---

## 2. 기믹 전체 목록 테이블 (문서 상단)

```yaml
| # | Name | 도입 Lv | PKG | 도입 간격 | Placement | Peer Equivalent |
|---|------|---------|-----|---------|-----------|-----------------|
| 0 | <기본 오브젝트> | 1 | 1 | - | 필드 | <레퍼런스 게임의 대응 기믹> |
| 1 | <기믹 1> | <Lv> | <PKG> | <레벨 차이> | 필드/큐/양쪽 | <피어 명> |
...
```

도입 간격 커브 권장:
- 초반(첫 5종): +10레벨
- 중반(6~10종): +20레벨
- 후반(11~12종): +40레벨
- 신규 없는 PKG도 의도적으로 배치 (기존 기믹 조합 심화)

---

## 3. 기믹별 명세 (개별 섹션)

각 기믹마다 아래 양식 그대로:

```markdown
## N. <기믹명>

**도입**: Lv.<N> (PKG <N>) | **카테고리**: 필드/큐/양쪽 | **Peer**: <레퍼런스>

### 동작 규칙
- <기본 동작 1>
- <기본 동작 2>
- <매칭/제거 방식>
- <상호작용 가능한 다른 요소>

### 난이도 레버
- <조절 가능한 파라미터 1: 효과>
- <조절 가능한 파라미터 2: 효과>
- 배치 위치 (어디에 두느냐로 난이도 변화)
- 수량 (몇 개 배치하느냐)

### 디자인 의도
- 주된 압박 축 (정보 불확실성 / 자원 압박 / 순서 강제 / 공간 제약 / 큐 물량 중)
- 1:1 매칭 규칙 위반 여부 명시
- 다른 기믹과의 차별점

### 피드백
- 이펙트: <시각 연출>
- 사운드: <효과음>
- 우선순위: P0 / P1 / P2 (feedback_direction_template.md 참조)
```

---

## 4. 기믹 축 분포

기믹들이 어느 압박 축에 속하는지 매핑. 축이 한쪽으로 쏠리면 다양성 부족.

```yaml
| 축 | 기믹 | 수 |
|---|-----|---|
| 정보 불확실성 | <Hidden계열> | <N>종 |
| 자원 압박 | <라이프 多 오브젝트> | <N>종 |
| 순서 강제 | <연결/잠금/얼림> | <N>종 |
| 공간 제약 | <벽/장벽/가림막> | <N>종 |
| 입력 물량 | <스포너/파이프> | <N>종 |
```

권장: 각 축에 최소 2~3종. 한 축이 비어있으면 디자인 공간 활용 미흡.

---

## 5. 상호작용 매트릭스 (핵심 조합)

기믹 2종 동시 등장 시 시너지 효과:
```yaml
| 조합 | 효과 | 디자인 의도 |
|------|------|-----------|
| A + B | <중첩 효과 설명> | <어느 압박을 극대화하는가> |
| C + D | <복합 효과> | <유저에게 요구하는 사고 차원> |
```

이 매트릭스는 후반 PKG (조합 심화 구간)의 레벨 디자인 근거.

---

## 6. 기믹 도입 원칙 (필수 준수)

### 6-1. 기믹 격리 (Hard Rule)
- 도입 레벨: **신규 기믹만** 등장. 기존 기믹 미등장
- 도입 후 2~3레벨: 해당 기믹만 사용 (적응 구간)
- 이후: 기존 기믹과 혼합 허용

### 6-2. 빈도 규칙 (Soft Rule)
- 6레벨 이상 연속 등장 금지
- 30레벨 이내 재등장 (망각 방지)

### 6-3. 종수 제한 (Hard Rule)
- 레벨당 기믹 최대 5종
- 같은 기믹의 변형(연결 수, 투명도 등 파라미터)은 1종으로 취급
- 같은 기믹의 파생끼리는 동일 레벨 혼합 금지 (예: 투명/불투명 파이프)

---

## 7. 1:1 매칭 규칙 (퍼즐 핵심 불변식)

직접 타격 기믹과 간접 제거 기믹을 구분:

| 유형 | 정의 | 예시 |
|---|---|---|
| 직접 타격 | 같은 색/형태 입력 단위로 1:1 매칭 | Wooden Board, Barricade, Paint Box |
| 간접 제거 | 다른 오브젝트 제거의 부수 효과로 라이프 감소 | Frozen Layer, Color Curtain |

→ **간접 제거 기믹은 입력 단위를 직접 소비하지 않음**. 1:1 원칙 보존.
→ **직접 타격 기믹은 라이프만큼 입력 단위 소비**. 1:1 원칙 유지하되 자원 압박 발생.

---

## 8. AI 지시사항 (기믹 명세 작성 시)

1. 도입 레벨/PKG는 Beat Chart와 일치 (cross_validation_template으로 교차 검증)
2. 파라미터화된 변형(연결 수/카운터/투명도 등)은 1종 취급 명시
3. **동일 기믹의 파생끼리 한 레벨 내 혼합 금지** 명시
4. 직접/간접 매칭 구분 명시 (1:1 원칙 보존)
5. 피드백 우선순위(P0/P1/P2)를 모든 기믹에 부여
6. Peer Equivalent를 반드시 기재 (피어 분석 추적성)
7. 상호작용 매트릭스는 핵심 조합만 (모든 N²이 아님)
