# 피드백 디렉션 템플릿 — 퍼즐 장르 공용

> 게임 이벤트 → (이펙트 + 사운드 + 진동) 매핑 표준.
> P0/P1/P2 우선순위 시스템으로 구현 일정 관리.
> 출처: BalloonFlow_피드백디렉션 (35개 이벤트) → 장르 일반화

---

## 1. 설계 원칙

- **모든 피드백을 우선순위로 분류**: P0(필수) → P1(권장) → P2(있으면 좋음)
- P0은 프로토타입/얼리 빌드에 반드시 포함
- P1은 소프트런칭 빌드
- P2는 소프트런칭 이후 폴리싱
- 게임의 코어 쾌감(터지는/제거되는 순간)은 **과하다 싶을 정도로 강조**
- 오브젝트 타입별 피드백 차별화 (예: 풍선=즉시 폭발, 피냐타=점진 파괴)

---

## 2. 우선순위 정의

### P0 — 필수 (Required)
> 이것 없으면 **게임이 안 되거나, 유저가 상태를 인지할 수 없는** 피드백.

대표 이벤트:
- 핵심 제거/매칭 성공 (코어 쾌감 — 이게 없으면 게임이 아님)
- 자원 위험 경고 (예: 게이지 80%+)
- 실패 판정
- 레벨 클리어 (기본)
- 부스터 사용 (작동 확인)
- 코인/재화 획득
- 핵심 인터랙션 확인음 (UI 버튼, 입력 단위 탭)

### P1 — 권장 (Recommended)
> 없어도 게임은 되지만 **쾌감과 몰입을 크게 높이는** 피드백.

대표 이벤트:
- 연쇄 제거 (콤보)
- 난이도별 클리어 차별화 (Hard/Super Hard 강화 연출)
- 비싼 부스터의 가치 체감
- 멀티 라이프 오브젝트 파괴 보상
- 패키지 클리어 마일스톤
- 부스터/기믹 해금 연출

### P2 — 있으면 좋음 (Polish)
> 디테일과 완성도를 높이는 피드백.

대표 이벤트:
- 기믹별 인지 (Hidden 공개, Frozen 해동, Lock 해제 등)
- 부스터별 고유 연출 (셔플, 손, 색상 제거 등)
- 보상 수령 / IAP 구매 완료
- 미세 인터랙션 (탄창 소진, 큐 변동 등)

---

## 3. 진동(햅틱) 강도 체계

### 2단계 강도 (전역 적용)

| 강도 | 지속 | 용도 |
|------|------|------|
| Light | 10ms, 약 | 일반 인터랙션 (탭, 제거, UI 버튼) |
| Heavy | 40ms, 강 | 거부 피드백 (비활성 탭, "이건 안 돼") |

### 전역 버튼 진동 (Light, P0)
모든 UI 버튼 탭 시 Light 진동. 별도 명시 안 해도 기본 적용:
- 닫기 [X], [Play], [Next], [Claim] 등 진행 버튼
- 부스터 슬롯 탭, 설정/뒤로가기 등 네비게이션
- 팝업 내 모든 버튼 ([구매], [취소], [확인])
- 큐/홀더에서 입력 단위 탭

→ **예외 없음**: 터치 가능한 UI 요소는 전부 Light 진동

### 인게임 기본 진동
| 이벤트 | 진동 |
|---|---|
| 입력 단위 탭 (활성) | Light 10ms |
| 입력 단위 탭 (비활성) | Heavy 40ms + 흔들림 연출 |
| 자원 배치/이동 (1단위마다) | Light 10ms |
| 핵심 오브젝트 제거 (1개) | Light 10ms |

## 4. 작성 양식 (이벤트별 매핑)

```markdown
| # | 게임 이벤트 | 이펙트 | 사운드 | 진동(햅틱) | 이유 |
|---|-----------|--------|--------|-----------|------|
| 1 | <이벤트 정의> | <시각 연출> | <효과음 명> | <Light/Heavy/-> | <왜 이 우선순위인가> |
```

각 이벤트는 P0/P1/P2 섹션 중 하나에 배치.

| 이벤트 | 이펙트 | 사운드 | 진동 |
|---|---|---|---|
| 핵심 제거 (1개) | 색상 파편 + 반짝 파티클 | 팡! (밝고 짧은 팝) | Light 10ms |
| 자원 위험 (80%+) | 게이지 빨강 + 깜빡임 | 경고 비프음 | — |
| 실패 판정 | 1.5초 딜레이 후 실패 연출 | 짧은 실패음 | — |

| 레벨 실패 (확정) | 시드는 연출 | 짧은 실패음 | — |
| 이어하기 팝업 | 팝업 등장 연출 | 주의 환기음 | — |
| 부스터 사용 (공통) | 부스터별 활성화 이펙트 | 부스터별 효과음 | — |

| 입력 단위 탭 (비활성) | 흔들림 연출 | 덜컹 (거부음) | Heavy 40ms |
| UI 버튼 (전역) | 눌림 연출 | — | Light 10ms |

## 6. P1 표준 이벤트

| 이벤트 | 이펙트 | 사운드 |
|---|---|---|
| 연쇄 제거 (2~4) | 파편 + 반짝 확대 + 콤보 숫자 | 팡팡팡! (피치 상승) |
| 연쇄 제거 (5+) | 파편 폭발 + 무지개 + 화면 흔들림 | 피치 상승 + 축하 효과음 |
| 클리어 (하드) | 노말 + 추가 폭죽 | 강화된 팡파레 |
| 클리어 (슈퍼하드) | 하드 + 화면 폭죽 + 특별 배너 | 최고 팡파레 |
| 비싼 부스터 (예: 색상 제거) | 대상 전부 동시 폭발 | 대폭발음 |
| 멀티 라이프 오브젝트 파괴 | 색종이 폭발 + 가려진 것 노출 | 빠악! + 축하 |
| 레벨 시작 | 등장 연출 | 경쾌한 시작음 |
| 패키지 클리어 | 완료 배너 + 다음 패키지 미리보기 | 성취 팡파레 |
| 부스터/기믹 해금 | 특별 등장 연출 | 해금 팡파레 |

## 7. P2 표준 이벤트 (기믹별 — 프로젝트마다 작성)

| 이벤트 패턴 | 예시 |
|---|---|
| 정보 공개 (Hidden 류) | ? → 실제 색 전환, 띵! |
| 해동/해제 (Frozen, Lock 류) | 얼음 깨짐 / 자물쇠 열림, 파삭/찰칵 |
| 차단 (Wall, Iron Wall) | 다트가 튕김, 딱! |
| 점진 파괴 (Wooden Board, Pin) | 금 가는 균열 + 흔들림, 쾅! |
| 큐 변동 (Pipe, Linked) | 새 입력 단위 등장, 톡! / 슉슉! |

## 8. 우선순위 요약 (프로젝트별 작성)

| 우선순위 | 수량 | 반영 시점 | 핵심 |
|---------|------|----------|------|
| P0 필수 | <N>개 | 프로토타입 | 코어 쾌감 + 상태 인지 + 과금 포인트 + 터치 진동 |
| P1 권장 | <N>개 | 소프트런칭 빌드 | 쾌감 증폭 + 난이도 차별화 + 기믹 보상감 |
| P2 폴리싱 | <N>개 | 소프트런칭 이후 | 디테일 + 조작감 + 기믹별 인지 |

---

## 9. AI 지시사항

1. **P0은 프로토타입 빌드에 반드시 포함** — 빌드 시 P0 누락 자동 검출
2. **"터지는 쪽은 과하게"** — 의심되면 강도를 올리는 방향
3. **기믹 명세 변경 시 P2 피드백 동시 업데이트**
4. **구체적 에셋(파일명, 파라미터)은 프로덕션에서 확정** — 디렉션 단계는 명세만
5. **진동은 모바일 햅틱 가능 환경에서만 활성** — PC/웹 빌드는 자동 비활성
6. **소리 무음 모드 대응** — 이펙트와 진동만으로도 상태 인지 가능해야 함
